Ryanair PA AP Agent

Monitor cen lotów Poznań → Alicante i Alicante → Poznań, połączony z jednym Kalendarzem Google właściciela.

Co robi aplikacja?

Sprawdza opublikowany rozkład i dostępne ceny lotów. Zapisuje ceny i datę odczytu w wydarzeniach kalendarza. Przy odpowiednio dużej zmianie tworzy alert oraz przypomnienie kalendarzowe. Nie kupuje biletów ani nie dokonuje rezerwacji.

Jak działa dostęp do Google?

Właściciel udziela zgody OAuth na dostęp do wydarzeń kalendarza. Agent odczytuje własne oznaczone wydarzenia, tworzy je i aktualizuje, a także porządkuje własne alerty. Konto autoryzujące musi mieć prawo edycji kalendarza docelowego. Ta strona nie jest formularzem logowania i nie przyjmuje tokenów.

Uruchamianie i ograniczenia

Kod i zadania działają w GitHub Actions, według godzinowego harmonogramu. GitHub może opóźnić lub pominąć uruchomienie. Źródło ofert Ryanair jest nieoficjalne i może być niedostępne. Cena jest obserwacją z określonej chwili, a nie gwarancją ceny przy zakupie. Dostarczenie przypomnienia zależy również od ustawień telefonu.

Projekt jest przeznaczony do osobistego użytku. Nie jest oficjalną aplikacją Ryanair i nie jest powiązany z przewoźnikiem.
