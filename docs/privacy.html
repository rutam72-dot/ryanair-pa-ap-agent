Polityka prywatności

Ryanair PA AP Agent jest osobistą automatyzacją właściciela projektu, a nie usługą rejestracji użytkowników.

Operator i kontakt

Operatorem jest właściciel repozytorium rutam72-dot/ryanair-pa-ap-agent. Pytania o dane i usunięcie dostępu można kierować na rutam72@gmail.com.

Dane i cel przetwarzania

Agent pobiera kierunki, daty i ceny lotów z Ryanair. Za zgodą właściciela korzysta z Google Calendar API do odczytu oznaczonych wydarzeń, tworzenia i aktualizacji wpisów cenowych oraz alertów i usuwania własnych nieaktualnych alertów. Przetwarzane pola obejmują identyfikatory, tytuły, opisy, daty, kolory, przypomnienia i znaczniki własności wydarzeń. Kod sprawdza też obecność uczestników, aby chronić wydarzenia współdzielone przed zmianami.

Agent nie korzysta z Gmaila, kontaktów ani plików Dysku Google. Zakres OAuth do wydarzeń może umożliwiać dostęp szerszy niż jeden kalendarz; kod ogranicza operacje do stałego kalendarza docelowego i oznaczonych wydarzeń. Zgoda nie służy reklamie ani profilowaniu.

Przechowywanie i publiczność danych

Dane OAuth są przechowywane w GitHub Actions Secrets i używane w pamięci procesu do wywołań Google. Nie powinny być umieszczane w kodzie, publicznych plikach ani logach. Stan roboczy w publicznym repozytorium zawiera daty lotów, ceny, czasy odczytu, identyfikatory własnych wydarzeń, planowane treści własnych wpisów i kolejkę operacji. Historia Git może zachowywać wcześniejsze wersje tych danych. Nie przechowujemy w nim kopii prywatnych wydarzeń użytkownika.

Logi Actions mogą zawierać diagnostykę, kierunki, daty, statystyki i identyfikator kalendarza. Mają okres przechowywania skonfigurowany przez GitHub i właściciela repozytorium. Ta strona nie używa analityki, skryptów śledzących ani formularzy. GitHub jako dostawca hostingu może przetwarzać dane techniczne połączeń zgodnie ze swoją polityką prywatności.

Odbiorcy danych

Google obsługuje autoryzację i kalendarz; GitHub hostuje kod, stan, logi i wykonania. Publiczny stan jest dostępny dla odwiedzających repozytorium. Danych Google nie sprzedajemy, nie wykorzystujemy do reklam i nie przekazujemy modelom AI do trenowania. Wykorzystanie danych otrzymanych z interfejsów Google podlega Google API Services User Data Policy, w tym wymaganiom Limited Use.

Wycofanie zgody i usuwanie danych

Właściciel może zatrzymać workflow i cofnąć dostęp aplikacji w połączeniach konta Google. Cofnięcie zgody zatrzymuje przyszły dostęp, ale nie usuwa istniejących wydarzeń, historii Git ani logów. Wydarzenia można usunąć w Kalendarzu Google, sekrety w ustawieniach repozytorium, a usunięcie publicznej historii wymaga osobnej operacji właściciela. Prośby dotyczące danych można zgłosić na adres kontaktowy powyżej.
